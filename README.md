
# SplameiPlay Update (Linux)

This repo's purpose it to host the scripts and signatures for SplameiPlay's Updater for Linux. It doesn't store anything else.

SplameiPlay Update (Linux) is a few simple bash scripts, each with specific tasks:
- `install.sh` - The initial script and installs `update.sh` to the device
- `update.sh` - The script that installs SplameiPlay and other required files
- `remove.sh` - The script that removes SplameiPlay from the device

## Requirements

> [!IMPORTANT]  
>  SplameiPlay Update (Linux) has only properly been tested currently in Debian so please expect issues with other distributions

- GNU/Linux
- A x64 processor
- A device capable of running Unity projects
- cURL (curl) installed
- bash present in `/bin/bash`
